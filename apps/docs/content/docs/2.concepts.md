You do not need these pages on day one.

Build a small app first. Come back here when a term starts to matter: caller, appIdentity, guard, operation, tenant, projection, or MCP.

The short version:

Browser pages, server routes, webhooks, and agents should call the same backend rules instead of each inventing their own.

::card-group
