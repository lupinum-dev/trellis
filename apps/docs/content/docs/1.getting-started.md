Start with the smallest app that proves Trellis is doing useful work.

Do not begin by wiring every feature. Generate an app, run `doctor`, build one live query, and make sure the page updates when Convex data changes. That tells you more than reading every concept page first.

## The path

If you are evaluating Trellis, read the cards top to bottom.

If you already have Nuxt and Convex running, skip to [First live query](/docs/getting-started/first-live-query). That page gives you the fastest useful signal: can Trellis read, write, and update the UI without extra refetch glue?

If you already know you need signed-in users, go from the live query page to [Build a signed-in todo app](/docs/getting-started/build-a-signed-in-todo-app). Do not start with workspaces or MCP unless those are real product requirements.
