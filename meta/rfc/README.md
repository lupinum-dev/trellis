# Requests For Comment

This directory contains proposed Trellis changes that are not yet accepted architecture decisions.

RFCs are intentionally more detailed than ADRs. They capture the problem, the proposed default,
tradeoffs, rejected options, and acceptance criteria. Once an RFC is implemented and the decision is
stable, keep only the durable decision in `meta/adr` or root foundation docs and delete stale planning
material.
